# 🏥 NearCare Rwanda

**NearCare Rwanda** is a healthcare discovery and navigation web application designed to help people in Rwanda quickly find nearby hospitals, clinics, health centres, and emergency facilities.

The platform addresses common healthcare-access challenges such as difficulty locating nearby medical facilities, limited access to healthcare information, and the need to quickly identify emergency care.

## 🌍 Project Overview

NearCare provides an interactive map-based experience that allows users to explore healthcare facilities across Rwanda. Users can search for facilities, filter them by type, view their locations on a map, check important information, and get directions to a selected facility.

The application is designed with a clean, modern healthcare interface that focuses on **accessibility, simplicity, and quick access to important medical resources**.

## ✨ Key Features

### 📍 Location Detection

Users can allow the website to detect their current GPS location and display it on the map.

The application then calculates the distance between the user and available healthcare facilities, making it easier to identify nearby options.

### 🗺️ Interactive Healthcare Map

NearCare uses **Leaflet and OpenStreetMap** to provide an interactive map of healthcare facilities.

Users can:

* View healthcare facilities on the map
* Zoom in and out
* Reset the map view
* Select individual facilities
* View their exact map locations
* See their current location

### 🔎 Healthcare Facility Search

Users can search for facilities by:

* Hospital name
* Clinic name
* District

This makes it easier to find a specific healthcare provider without manually searching through the entire map.

### 🏥 Facility Categories

Healthcare facilities can be filtered into different categories:

* Hospitals 🏥
* Clinics 🩺
* Emergency facilities 🚨
* Health centres 💊

### 📏 Search Radius

Users can choose how far they want to search for healthcare facilities using an adjustable radius.

The radius can be changed from **1 km to 50 km**, allowing users to focus on facilities within a practical distance.

### ⭐ Facility Ratings

Healthcare facilities display ratings to help users quickly compare available facilities based on their displayed rating data.

### 🏥 Facility Information

Selecting a facility displays additional information such as:

* Facility name
* District
* Distance from the user
* Opening status
* Rating
* Available services
* Telephone number

### 🧭 Get Directions

Users can select a healthcare facility and open directions through Google Maps to help them navigate from their current location to the selected facility.

### 📞 Emergency Assistance

NearCare includes an emergency-access feature that allows users to:

* Quickly find emergency healthcare facilities
* Automatically filter emergency facilities
* Highlight the nearest available emergency facility
* Quickly call emergency services using the emergency button

### 📞 Direct Facility Calling

Users can directly call a healthcare facility from the facility information panel using their phone.

## 🇷🇼 Rwanda Healthcare Focus

NearCare is specifically designed around the Rwandan healthcare context.

The project aims to make healthcare information easier to access by bringing healthcare facilities, locations, services, emergency access, and navigation together in one platform.

The application can be expanded to cover healthcare facilities across Rwanda's districts and provinces.

## 🎯 Problems the Project Addresses

NearCare was created to address several healthcare-access problems:

1. **Difficulty finding nearby healthcare facilities**
2. **Difficulty identifying emergency facilities quickly**
3. **Limited access to healthcare information**
4. **Difficulty comparing nearby facilities**
5. **Lack of simple map-based healthcare discovery**
6. **Need for quick access to emergency contact services**
